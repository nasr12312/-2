# منصة مدارس غراس الأخلاق

منصة عربية RTL لمتابعة القرآن الكريم، التقييم السريع، المقرأة، رفع التسميع صوتًا أو فيديو، ولوحة مختصرة لولي الأمر بصلاحية المشاهدة فقط.

## البيانات المعتمدة

- 340 طالبًا من ملفات المدرسة: 66 في الدبلومة و274 في ثنائي اللغة.
- 31 صفًا وشعبة منفصلة حسب البرنامج.
- 721 تكليفًا قرآنيًا مستخرجًا من استمارات Word للصفوف المرفقة.
- 7 حسابات للمعلمين والمشرفين بالأسماء المعتمدة.
- لا تُستورد من ملفات الطلاب أي بيانات شخصية سوى اسم الطالب ورقمه الوطني. الصف والشعبة والبرنامج علاقات تنظيمية لازمة لتشغيل المنصة.
- ملف الدبلومة الأصلي لا يحتوي أرقامًا وطنية؛ لذلك تكون حساباته بحالة `بانتظار الرقم الوطني` حتى إدخال الرقم الحقيقي.

الملفات التي تحتوي بيانات الطلاب ورموز الدخول تُنشأ داخل `private-data/`، وهذا المجلد مستبعد من Git حتى لا تُنشر الأرقام الوطنية على GitHub.

## الدخول والصلاحيات

- ولي الأمر يدخل بحقل واحد: الرقم الوطني للطالب.
- المعلم يدخل برقم المعلم، ثم يختار البرنامج والشعبة في أول دخول، فتُحمّل قائمته تلقائيًا.
- ولي الأمر يشاهد الاسم، الصف، المقرر، آخر تقييم، ملاحظة المعلم، والواجب أو التسميع المطلوب. لا يستطيع تعديل السجلات.
- المعلم يرى طلاب شعبه فقط. المشرف والإدارة يملكان الصلاحيات المحددة في سياسات قاعدة البيانات.
- ملفات الصوت والفيديو خاصة وتُحفظ في bucket غير عام، بحد أقصى 25 ميجابايت.

## قاعدة البيانات

الملف `supabase/migrations/20261001000100_initial_school_platform.sql` ينشئ الجداول والفهارس وسياسات RLS وصلاحيات Data API ومساحة ملفات التسميع الخاصة.

1. أنشئ مشروع Supabase.
2. نفّذ ملف migration في SQL Editor أو عبر Supabase CLI.
3. انسخ `.env.example` إلى `.env.local` وضع رابط المشروع والمفتاح القابل للنشر.
4. شغّل مستورد البيانات محليًا. ثم ضع `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` في بيئة الطرفية وشغّل `pnpm seed:database`.
5. احذف مفتاح الخدمة من الجلسة بعد الاستيراد. لا يُستخدم هذا المفتاح في الواجهة ولا يُرفع إلى GitHub.

الاستيراد قابل لإعادة التشغيل: يحدّث السجلات والحسابات الموجودة دون تكرارها. يُنشئ حسابات أولياء الأمور لطلاب ثنائي اللغة فقط حاليًا لأن أرقام الدبلومة غير موجودة في الملف المصدر.

## التشغيل

```bash
pnpm install
pnpm build
node server.mjs
```

ثم افتح `http://127.0.0.1:4173`.

عند عدم وضع مفاتيح Supabase تعمل الواجهة في وضع معاينة محلية. عند وضع المفاتيح تنتقل تلقائيًا إلى دخول المدرسة وقاعدة البيانات الحقيقية.

## الفحص

```bash
pnpm test
pnpm build
```

تم اختبار منطق عزل صلاحيات ولي الأمر، توزيع الآيات، مفاتيح التقييم، الحضور، والاختبارات، إضافة إلى بناء الإنتاج باستخدام TypeScript وVite.
